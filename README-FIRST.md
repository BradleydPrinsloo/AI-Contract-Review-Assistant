# ContractIQ — README FIRST

ContractIQ is a local-first Windows desktop contract-intelligence scanner. It helps reviewers open a PDF, DOCX, or TXT contract, identify important clauses, review an explainable risk score, and export professional reports.

## First run

1. Extract the complete portable ZIP before launching it.
2. Double-click `START-HERE.cmd`.
3. Choose **Open Contract**.
4. Select an authorized contract file.
5. Choose **Scan Contract**.
6. Review the summary cards, findings table, and executive summary.
7. Generate a report only after a human reviewer checks the findings.

## Data location

Packaged builds store editable rules and scan history under `Documents\ContractIQ Exports\` by default. Development runs store generated data in the repository-local `exports/` folder.

## Important notice

ContractIQ is a decision-support tool. It does not provide legal advice and does not replace qualified legal or business review.
